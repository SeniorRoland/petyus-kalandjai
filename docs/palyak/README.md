# Petyus kalandjai – a pályák leírása

Játékosoknak szóló leírások: mi történik a pályán, milyen csibészségek vannak, hogyan kell őket teljesíteni, milyen feltételekkel, és mi kell az 1, 2 és 3 csillaghoz.

| Rész | Pálya | Csibészségek | Leírás |
|---|---|---|---|
| 1. Augusztus | A park | 10 (30 ★) | [Leírás](1-park.md) |
| 2. Szeptember | Otthon, reggel (6:00–7:30) | 3 | [Leírás](2-otthon-reggel.md) |
| 2. Szeptember | Az iskola (8:00–15:30) | 4 | [Leírás](2-iskola.md) |
| 2. Szeptember | Otthon, este (16:00–22:00) | 3 | [Leírás](2-otthon-este.md) |

- **Csillagok:** minden csibészség legfeljebb 3 ★ (★ teljesítés, ★★ / ★★★ mérhető eredményért); mindig a **legjobb** eredmény számít, minden újrajátszható. A kezdőképernyőn minden rész csempéjén ott a saját ⭐ megszerzett / megszerezhető száma.
- **A 2. rész** az 1. rész **15 ★**-ja után nyílik meg; a 2. rész 30 ★-ja külön számít.
- **Csibészség-napló:** **N** vagy 📒 – az elvégzettek csillagokkal és a legjobb eredménnyel, a többinél „???” és egy tipp.
- **A játékban:** játék közben a 📖 gomb (vagy az **L**) az épp játszott pálya leírását nyitja meg (a játék addig áll); a kezdőképernyőn a „📖 Pályaleírások” gomb.
- **Telefonon:** [Játék telefonon](mobil.md).

> Fejlesztőknek: a tervek a `docs/terv-*.md`-ben. Karbantartás: ha egy csibészség menete vagy csillagfeltétele változik (`MISCHIEFS` / `MISCHIEFS2` a `src/mischief.js`-ben), az itteni leírást is frissíteni kell.
