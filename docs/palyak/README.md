- **Csillagok:** minden csibészség legfeljebb 3 ★ (★ teljesítés, ★★ / ★★★ mérhető eredményért); mindig a **legjobb** eredmény számít, minden újrajátszható. A kezdőképernyőn minden rész csempéjén ott a saját ⭐ megszerzett / megszerezhető száma.
- **A 2. rész** az 1. rész **15 ★**-ja után nyílik meg; a 2. rész 30 ★-ja külön számít.
- **Csibészség-napló:** **N** vagy 📒 – az elvégzettek csillagokkal és a legjobb eredménnyel, a többinél „???” és egy tipp.
